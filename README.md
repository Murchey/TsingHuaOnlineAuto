# 清华社英语在线练习助手

TypeScript 用户脚本，可安装在脚本猫或篡改猴中。0.1.2 同时识别新版 Vue 阅读器与旧版 `/legacy/course-study-student/...` Angular 学习页。

## 本次修复

0.1.0 只支持新版阅读器，而实际登录的课程仍使用 Angular 7.2.16 旧版，导致一直显示“未检测到可用练习”。0.1.1 增加旧版组件发现、正常练习数据读取、UUID 题目标识及刷新恢复、旧版填写与提交适配。0.1.2 增加旧版角色扮演 `legacy_9` 的原生语音评测和右箭头连续下一题。

2026-10-27 已在用户指定的运行中 Chromium 浏览器验证：识别旧版练习、读取服务器记录、跳过已有完整作答、切页后继续识别。`legacy_9` 的真实录音与连续提交仍需在脚本管理器更新后实测。**当前页面采用临时注入测试，仍需在脚本管理器中更新安装脚本，才能刷新后继续使用。**

## 安装或更新

1. 停用旧版“清华社视听说修改版 - 自动答题”和其他自动答题脚本，刷新网页。关闭旧面板不会撤销旧脚本已安装的网络与录音钩子。
2. 在脚本猫／篡改猴编辑本助手，将 `dist/tsinghua-online-auto.user.js` 的**全部内容**替换进去，保存并启用。确认面板版本为 **0.1.1**；`.meta.js` 不能单独运行。
3. 刷新网页后进入课程或教材的日常练习。右下角面板应列出当前练习；旧版带“旧版”及待作答／结果页标记。
4. 点击“开始”。服务器已有完整作答会保持原结果，不点击 Retry／ReChallenge。默认只处理当前块，不自动翻页或重做已提交练习。
5. 首次实际提交后手动刷新确认记录仍存在。遇到问题点“导出诊断”。面板收起后点击右下角按钮或按 **Alt+Shift+T** 恢复。

## 提交与恢复

提交前保存本地待核对记录，点击原站 Submit 一次；随后重新读取服务器，检查提交次数增加并逐题匹配内容。结果不确定时保留待核对状态，不自动重试。刷新后的继续也先核对。重置记录前请先在网页确认是否真的需要重新提交。

新版可勾选处理当前章节已加载的练习块；旧版按当前页面处理。Web Locks 防止同来源、同浏览器配置的多标签页并发；不覆盖其他浏览器配置或手动提交。暂停／停止中断后续动作和等待，已发送请求无法撤回。

旧版桥接固定适配已检查的 Angular 7.2.16 和 `main.4c93dc9c6da8077cd693.js`。网站发布新构建后可能需重新适配。出现“无法访问组件”请导出诊断，不要用解除路由或权限检查的方式强行运行。

## 开发

Node.js 22+：

```powershell
npm ci
npm run check
```

`check` 执行类型检查、构建和测试，安装产物在 `dist/`。源码、测试及适配记录分别在 `src/`、`tests/`、`docs/`。`scripts/browser-console.ps1` 仅用于开发时通过 Windows UI Automation 操作已打开 DevTools 的指定浏览器窗口，必须传入主进程 `BrowserProcessId`；它不会启动浏览器。

不保存密码、登录令牌或录音到仓库，不主动上传诊断，不依赖外部 CDN。诊断不含题干、选项、答案、音频、Cookie 或 URL 查询参数；旧版路径中的账号段已脱敏。完整课程响应和公开站点资源仅保存在忽略的 `.cache/`，不交付。
